# Python Projects 🐍

A collection of Python projects I’m building while learning and improving my Python programming skills.

These projects are based on the [GeeksforGeeks Python Projects](https://www.geeksforgeeks.org/python/python-projects-beginner-to-advanced/) list. I’m implementing the projects myself to practice programming concepts, problem-solving, and writing cleaner and more structured code.

This repository includes small projects such as number guessing, word guessing, the 21 number game, and Rock Paper Scissors. More projects will be added as I continue learning Python and move toward backend development.

The projects are mainly for learning and practice, and I may revisit and improve them as my skills develop.
